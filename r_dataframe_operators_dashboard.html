1 · Data frame

      
    
        
  • A data frame is a table: columns are vectors of equal length.
    • 
        
  • data.frame(item = c(...), price = c(...), qty = c(...))
    • 
        
  • nrow(), ncol(), names() describe its size and columns.
    • 
      

    
2 · Picking data

      
    
        
  • shop$price – one column.
    • 
        
  • shop[2, "item"] – row 2, column "item".
    • 
        
  • shop[shop$price > 100, ] – rows that pass a test.
    • 
        
  • shop[order(-shop$revenue), ] – sort rows.
    • 
      

    
3 · Arithmetic operators

      
    
        
  • + - * / and ^ work on whole columns at once.
    • 
        
  • %/% – whole-number division (packs of 10).
    • 
        
  • %% – remainder (items left loose).
    • 
        
  • shop$revenue <- shop$price * shop$qty adds a new column.
    • 
      

    
4 · Comparison operators

      
    
        
  • >  <  >=  <=  ==  != give TRUE or FALSE.
    • 
        
  • On a column they give one TRUE/FALSE per row.
    • 
        
  • Remember: == compares, = / <- assign.
    • 
      

    
5 · Logical operators

      
    
        
  • & – AND: both must be TRUE.
    • 
        
  • | – OR: at least one TRUE.
    • 
        
  • ! – NOT: flips TRUE and FALSE.
    • 
        
  • Try them in the "Show rows where" box on the dashboard.
    • 
      

    
6 · Summary functions

      
    
        
  • sum(), mean() on a column.
    • 
        
  • which.max() – row number of the biggest value.
    • 
        
  • paste(..., collapse = ", ") – join names into text.
    • 
      

    
Ideas to extend the project

      
    
        
  • Add a discount column: shop$price * 0.9.
    • 
        
  • Use ifelse(shop$qty < 10, "Restock", "OK") to flag low stock.
    • 
        
  • Read the table from a file with read.csv("shop.csv").
    • 
      

  







  

    
Run the project in R

    
    
      
  1. Install R (and optionally RStudio) from cran.r-project.org.
    2. 
      
  2. Open the R Code tab and click Download shop_sales.R (or copy the code into a new script in RStudio).
    3. 
      
  3. In RStudio press Source, or from a terminal run: Rscript shop_sales.R
    4. 
      
  4. Change min_revenue or cheap_limit at the top and run again — compare with the console panel on the dashboard.
    5. 
      
  5. In the R console, type shop or View(shop) after sourcing to see the whole data frame.
    6. 
    

    
Note: this dashboard re-implements the same logic in JavaScript so it can run live in a browser. The R script is the actual project; the dashboard is its visual front end.
